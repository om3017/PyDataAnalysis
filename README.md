| Sales Data Analysis |
Turning raw sales data into actionable business insights using Python, Pandas, Seaborn & Matplotlib.

🚀 Project Overview
This project performs an Exploratory Data Analysis (EDA) on sales data to identify patterns and trends across:

👥 Customer age groups and gender
💼 Customer sectors
🌍 Geographical zones
🏙️ States
🛍️ Product categories
📦 Number of orders
💰 Sales amount

The objective is to transform raw sales data into meaningful insights that can help businesses understand customer behaviour, high-performing markets, product demand, and areas requiring strategic improvement.


🎯 Business Objectives

The analysis aims to answer questions such as:

Which age group contributes the most customers?
Which sectors generate the highest number of orders?
Which zones contribute the highest sales amount?
Which states are the strongest sales performers?
Which product categories receive the most orders?
Which regions and customer segments require more attention?
Where can businesses focus their marketing and sales strategies?


🛠️ **Tools used**

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
- Excel


📈 Visualizations

The project contains multiple visualizations, including:

📊 Age Group-wise Gender Count
📈 Sector-wise Total Orders
🥧 Zone-wise Sales Amount
📊 Top 10 States by Sales Amount
📊 Zone-wise Total Orders
🥧 Product Category-wise Orders
📈 State-wise Sales Amount

These visualizations make it easier to identify patterns and communicate business insights.
